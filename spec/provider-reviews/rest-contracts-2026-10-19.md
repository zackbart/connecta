GETs below are reads; mutating methods are writes except the two explicitly reviewed stateless Cloudflare POSTs. Value safety is a separate verdict from read/write. `safe` means no documented credential/stored secret response; the shared key-name and URL defenses still apply. Free text supplied by users, arbitrary application JSON, and source code are outside the stored-secret guarantee. `redact` applies before selection and truncation; `refuse` stops before dispatch.

### Other Vercel contract changes

The six generated request changes are: AI Gateway budgets filters/pagination, rules filters/pagination, virtual-model-config list pagination; Node `26.x` in deployment/project settings; sandbox command POST no longer requires `cmdId`; project update no longer accepts `trustedIps.protectionMode`. `GET /v2/teams` has a new response contract digest; the existing invite-code redaction still applies. New response candidates also include budget API-key coverage **counts** and remote-cache `readOnly` status, both safe metadata. Connect capability `isStaticCredential` fields are booleans, not tokens. Project-list `security.firewallRoutes[].response_has[].value` needs the same header/cookie/query redaction as existing matches; the shared project rule covers it, acknowledging other project shapes that do not yet declare this field.
