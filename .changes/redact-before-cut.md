A sent credential or private argument echoed back by a downstream service can no longer reach an agent in part because connecta cut the text it was in. Error messages, capped fields, and paged text are now redacted whole before they are shortened, everywhere connecta or a maintained provider shortens them: Google Workspace error messages and every Gmail, Drive, Docs, Sheets, Forms, and Slides field, body, and page; Vercel, Cloudflare (including GraphQL and success-status failures), CCB, Overflow, and Breeze error text; Vercel log lines; and remote MCP error text, whose cut now also sees the request's private arguments. A Drive text download that stops inside a sent value, and a Notion property Notion stopped listing, drop that tail. Before this, a cut through an echo, in any of the encodings redaction covers, left a fragment no registered form matched; a Google 401 could show 22 of an access token's 31 characters.

Complete matches and unfinished tails are merged against the original text before replacement, including one-unit prefixes and partial JSON escapes. Redaction precedes trimming, normalization, and date extraction; Notion's truncated rich text is protected before titles, search results, flattened properties, and raw responses copy it. Slides text and raw-chunk cursors bind the redacted representation even when the vendor revision is unchanged, refusing continuation if a different request secret set changes its offsets.

Redaction now matches fragments, not only whole values. Every redaction projects the whole value, string and number leaves in order with nested JSON and error fields, and matches it joined, so a value split across adjacent leaves is found and replaced in each piece. No caller-visible text keeps a registered form whole or any run of eight consecutive units of one (in the raw text or any JSON-decoded layer), and cut text still loses an unfinished tail of any length at every decoding layer. A private value of one to three characters matches only a whole field value, so ordinary text around it stays; one of four to seven characters also matches wherever it occurs in payload text, numbers, keys, and decoded views. Every string that can reach an agent or storage, object keys, declared binary fields, cursor claims and structural fields included, now goes through one checker with every check below. Declared binary content, a REST body's `base64`, and base64 or base64url anywhere in any field or key is decoded and checked, in the text as it stands, under one layer of JSON escapes, with its percent escapes decoded, and with a `+` read as a form-encoded space whether or not a percent escape is present; declared content that is not valid base64 as it stands gets every one of those views too; a run inside text is decoded from six characters when a short private value is registered and from eleven otherwise, the shortest that can carry what is matched at any alignment, padded or not. Every encoding connecta returns itself, downloads and page cursors included, is checked before it is encoded: vendor page tokens and Slides page ids enter cursors redacted, and every string in a cursor is checked under payload rules. A payload can no longer claim a framing exemption: only fixed words, outcome booleans, and a connecta error's own code and class name are kept whatever was sent. Redaction returns a caller's object or array as it stands only when it is verified plain data; everything else, every error included, is returned as a copy of checked, writable data fields, so a `toJSON`, an inherited array hole, a getter or another class's fields cannot change what a later read or serialization sees, a frozen input never makes redaction throw, and identity facts such as an HTTP status follow array and error copies. Redaction returns only JSON data, a fresh `Uint8Array` and error copies: a function or symbol is withheld, so a `toJSON` it carries never runs at an exit; a typed array, `DataView` or `ArrayBuffer` of any class becomes a plain `Uint8Array` of its bytes, withheld when its bytes or the numbers JSON shows for it hold a match; a `String`, `Number` or `Boolean` wrapper becomes its primitive; an error copy shadows `toJSON` without reading it; and a `toJSON` result whose fields were copied is never put back as the original. A container too large to walk is withheld whole instead of being serialized unchecked, so the result stash cannot keep it. Docs link and paragraph text, Notion rich text in both copies, Slides raw text runs, Planning Center and Tithe.ly error trimming, Docs previews, and Drive size strings are checked at their source; Notion keeps earlier public runs when only an unfinished tail changes. Confidential client IDs, Basic usernames beside a password and identifier-named credential fields match whole only, and continuation cursors and connecta's own public token-request header values are not registered, so their public parts survive; any other configured token-request header value is. A value that embeds ordinary text, such as a password holding a word, also redacts that text where it recurs in the same request.
