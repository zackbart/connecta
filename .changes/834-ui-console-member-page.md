Endpoints shows who can use each endpoint: `/mcp` lists its maintainers and each pool its members, people by name (or raw id) and agents as `agent:<name>`, with long lists collapsed behind "+N more". Tokens lists one row per agent declared in code with its pools, token state, date and last seen; issue, rotate and revoke keep their confirmations, a new secret appears once in a dialog, an unknown or aborted outcome is a failure notice that is never retried, and an agent missing from the live slot list cannot be acted on until a refresh lists it. Pool members get their own page with their endpoints and client setup, connect, reconnect or disconnect for their personal OAuth accounts, a credential form for personal credential slots whose Add, Replace, Test and Clear follow `manage.actions`, and the names of connectors shared with them. Every token and member action is checked again immediately before it is sent, so a slot list or contract refreshed meanwhile stops it, and a token operation with an unknown outcome disables that agent's controls until a refresh. The operator UI's dependency notices keep one copy of each distinct license text. Token mutations send the slot revision the operator confirmed against as `expect` once the route lists revisions (P3b of #837), and a 409 `slot_changed` reads "Changed since you looked, refresh".
