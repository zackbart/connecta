Machine clients are agents declared by name in a new top-level `agents` option, each with one `cta_` token slot that operators issue, rotate, and revoke from `/ui/access-tokens`, the operator UI, or `AccessTokenManager.rotate` and `revoke`. Rotation is an immediate cutover: the old secret refuses on its next request, and of concurrent rotations exactly one returns a secret. The agent's slot is the only authority admission consults, and each operation commits by one compare-and-set on it and only moves forward: a rotation cancelled before its commit publishes nothing, and one cancelled after it moves the slot to revoked within one deadline that bounds every storage call of the operation, the commit's acknowledgement included (otherwise it reports the outcome unknown, never success; rotate again for a replacement secret). The request path deletes nothing it did not just write: superseded records and lookups stay behind, inert, so storage grows by one small record per rotation or adoption. A token admits only while it is bound to a currently declared agent, so removing a name stops its token on the next request. Admitted agents carry `identity.agent` (set only by the built-in adapter; any other provider returning `agent` is refused), have no principal and so no personal connectors, and are attributed in activity by agent name rather than token record id. Breaking: creating, renaming, and human-bound tokens are removed from the routes, manager, and UI; tokens issued by earlier releases stop admitting until trusted provisioning adopts each machine token for an agent with `AccessTokenManager.adopt(tokenId, agent)` (Node template: `npm run adopt-token`), which keeps its secret without rewriting the legacy record and takes a never-deleted claim so a legacy token is adopted by at most one agent, once, and human-bound tokens cannot be adopted; `accessTokens(storage, { maxActive })` throws; `describeConfig()` adds `agents` and drops `modules.accessTokens.maxActive`; grant callbacks that matched token record ids should match `identity.agent`. The Node template replaces `provision-token` with `npm run rotate-token -- <agent>` and declares `local-machine`.
