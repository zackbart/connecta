Settings and the connector Configuration card show configuration as tiles instead of a key/value tree: fact chips for the deployment, sign-in tiles with provider marks and maintainer avatars, on/off feature tiles, and limits as large formatted values (1 MB, 1 min, 30 days) where a value set in code carries an accent dot and defaults recede. A connector's card shows badges for its kind, auth scope and auth, then tiles for its limits. Snapshot keys the UI does not map still appear as labelled tiles.
