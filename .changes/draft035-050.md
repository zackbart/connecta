Require Node deployments to serve with `listen()` from `@zackbart/connecta/node` and install `undici@6.29.1`. Without its owned sender, every maintained-provider write, every reviewed POST read and every remote MCP write is refused before sending, although each worked in 0.34.1. With `listen()`, every maintained-provider request, reads included, remote MCP writes and downstream OAuth credential POSTs use the owned sender. It connects directly by default or through an explicit HTTP(S) CONNECT `proxy` option, ignoring `NODE_USE_ENV_PROXY`, `HTTP_PROXY`, `HTTPS_PROXY` and host proxy dispatchers. Remote MCP reads and OAuth discovery GETs retain native fetch and need their own host proxy policy.
