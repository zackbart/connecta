**No registration endpoint's or discovery document's text reaches an agent or
a log.** The SDK quotes a refused dynamic client registration's response body
whole, beside the metadata connecta submitted, and that error reached
`authorize_connector`, status, and tool results as it stood; an issuer or
resource mismatch quoted the URLs the metadata named. A server that controls
that text can echo the request or plant whatever it likes for an agent to
read. A refused registration is now connecta's own sentence — the
registration endpoint's origin, the status, and the OAuth `error` code if it
is a registered one — and any other failure of an OAuth flow, at connect or
on a live client, names the step, the host of that flow's own last request,
and the SDK's error class; concurrent calls never borrow another flow's step.
Google's delegated token endpoint no longer has its `error_description`
quoted as "Google said"; its refusals name the step, host, status, and code.
Each keeps the classification the original would have had, so `retryable`
and the code an agent sees do not move (#695).
