Search counts two weak zones toward coverage: a connector's configured title and description (every tool of that connector matches, so `money` reaches a connector titled "Money tracker") and a tool's top-level input property names and descriptions. Neither makes a match complete. A short shared synonym map (`email`/`mail`/`gmail`, `schedule`/`calendar`/`agenda`, `meeting`/`event`, `spend`/`expense`/`transaction` and a dozen more) widens query words on every connector, ranked below the word itself.
