Search counts two weak zones toward coverage: a connector's configured title and description (every tool of that connector matches, so `money` reaches a connector titled "Money tracker") and a tool's top-level input property names and descriptions. Neither makes a match complete. Input property text is indexed within fixed per-tool and per-catalog budgets. A short shared synonym map (`email`/`mail`/`gmail`, `schedule`/`calendar`/`agenda`, `meeting`/`event`, `spend`/`expense`/`transaction` and about a dozen more) widens query words on every connector, ranked below the word itself, and completes a match only where no tool states the word literally.
