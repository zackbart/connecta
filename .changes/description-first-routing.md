Every meta-tool description, and Connecta's own tools on native pools, now opens with a first line of at most 120 characters saying what the tool is for and when to use it instead of its siblings, for hosts that never show server instructions or show only that line. Descriptions stay within 4,096 characters and remain byte-identical for one configuration across requests and processes. The connector inventory no longer repeats a title's leading words in a purpose and clips on a whole clause, never leaving a parenthesis open or a trailing dash or joining word. Changing the configured connector roster changes the `execute_code` and `execute_read_code` descriptions, so hosts that remember approvals by description text may ask again; this release changes every description once.
