Search shows a tool that several connectors offer identically once, at its best rank, with the other callable addresses in the row's `alsoOn` and their connectors in `connectors`; the row shown is the account the query names, when it names one. Only rows the caller can already see are grouped, and `total`/`nextOffset` count rows after grouping; a browse still lists every address. A query that names every word of a connector ID in any order now routes to that connector, so `work mail threads` ranks `mail_work` above `mail`.
