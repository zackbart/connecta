A maintained Google Calendar provider, `@zackbart/connecta/providers/calendar`, in both Google modes (domain-wide delegation and OAuth) with the full `https://www.googleapis.com/auth/calendar` scope. Named tools list calendars, list and search events, read an event, query free/busy, create events (guests, reminders, recurrence, an optional Google Meet link), quick-add, update events while preserving other guests' responses, answer invitations, move and delete events. Invitation emails follow each write's explicit `sendUpdates`. The hatch admits every indexed Calendar method behind a reviewed verdict and refuses only push notification channels. Conference dial-in PINs and passcodes are withheld. (#1395)
