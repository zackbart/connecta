Connecta-authored agent text and maintained providers name routes with the names of the surface serving them, resolved when the text is built, instead of spelling meta-tool names. The six-tool surface is byte-identical. Native pools no longer rewrite a caller's unknown tool name, programs on native pools see native recovery wording in failures they catch, and native pools serve provider notes, schema descriptions and authorization errors in complete native phrases with that pool's paging. Custom connectors can build such text from the new optional `ConnectorContext.routes` (`AgentRouteNames`).
