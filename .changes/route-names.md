Connecta-authored agent text and maintained providers name routes with the names of the surface serving them, resolved when the text is built, instead of spelling meta-tool names. The six-tool surface is byte-identical. Native pools no longer rewrite a caller's unknown tool name, and programs on native pools see native recovery wording in failures they catch. Custom connectors can build such text from the new optional `ConnectorContext.routes` (`AgentRouteNames`).
