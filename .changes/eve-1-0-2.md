`@zackbart/connecta-eve` now supports stable Eve 1.x, with peer range `^1.0.2` instead of an exact `1.0.0-rc.10` pin. Update the app to `eve@^1.0.2`, reinstall, rebuild and test before deploying. The helper's APIs are unchanged; see the helper README's upgrade notes for the app-owned changes in Eve rc.11 through 1.0.2, including MCP connections that no longer fall back to `initialize` after a failed `server/discover` request, the Node.js 26 project target and dynamic schedule `auth` returning `null`.
