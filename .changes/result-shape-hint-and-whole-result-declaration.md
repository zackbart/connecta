`execute_code` programs that fail reading a property of undefined or null because they read a payload field straight off an awaited `connecta.call`, `connecta.search` or `connecta.describe` result now get the `{ data, format }` / `{ tools }` shape hint under both QuickJS and V8 wording. This covers a local bound to the result (even one named `data`), a member chained off the awaited call, and a key destructured from it. Other failures keep the generic hint, and `connecta` named only inside comments or strings no longer triggers the shape hint. The `result()` declaration in the tool description now includes the `connecta.result(id, { all: true })` form that recovery text tells agents to use. The connector inventory in the `execute_code` and `execute_read_code` descriptions is capped at 1,024 bytes, or less where the description would otherwise pass the 4,096-character host cut-off, so a full roster on a deployment with large limits can no longer push the description past it.
