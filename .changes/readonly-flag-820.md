Each endpoint is now writable or read-only, set by a plain `readOnly` boolean on the deployment (for `/mcp`) and on each pool, replacing pool `trust`. The client owns approval. A writable endpoint behaves as a `trusted` pool did: `call_destructive_tool` and `execute_code` programs write, capped by `execute.maxWrites`, `call_tool` still refuses writes, and `execute_code` is annotated `readOnlyHint: false, destructiveHint: true`. A read-only endpoint writes nothing: write tools are absent from `search_tools`, `connecta.search`, and `connecta.describe`; `call_tool`, `call_destructive_tool`, and program writes are refused before validation or dispatch with the new code `read_only_endpoint` (`retryable: false`, no `nextAction`); and `execute_code` is annotated `readOnlyHint: true, destructiveHint: false`. `tools/list` stays six tools on both. The deployment defaults to `readOnly: false`, and a pool inherits the deployment value unless it sets its own, in either direction. Resource reads, grants, `connectorAccess` (including guarded `requireReadOnly` grants), classification, and `execute.maxWrites` are unchanged. `describeConfig()` and the operator UI report `readOnly` instead of `trust`, and programs no longer receive `destructive_tool_requires_approval`, which remains `call_tool`'s refusal of a write on a writable endpoint.

To migrate, edit every `trust` in deployment code; a config that still sets it, on the deployment or a pool, fails at construction with a message naming `readOnly`. Replace `trust: "trusted"` with `readOnly: false`, or remove it, since that is the default. Replace `trust: "read-only"` with `readOnly: true`, and note that a read-only endpoint now also refuses `call_destructive_tool` and hides writes from discovery; a pool that should still allow host-approved direct writes but no program writes has no equivalent and must choose. Pools and a root `/mcp` that relied on the old read-only default now inherit a writable deployment, so set `readOnly: true` explicitly on the deployment or on each pool that must stay read-only.
